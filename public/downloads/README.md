# Downloads públicos

Instaladores do BRS Downloader servidos pelo site para atualização in-app.

Mantenha **apenas a versão atual** aqui — cada `.exe` entra em todo deploy e soma no storage.
Versões antigas devem ir para GitHub Releases / outro CDN.

- `BRS-Downloader_1.0.10_estable_x64-setup.exe` — Windows x64 (NSIS) — **atual**
- `BRS-Android_1.0.0-debug.apk` — Android (debug) — app WebView do site

Allavsoft: download externo (Workupload) via `getAllavsoftDownloadUrl()` —
padrão `https://workupload.com/file/ZtbqKQUe6BV` (sobrescreva com `ALLAVSOFT_DOWNLOAD_URL`).
