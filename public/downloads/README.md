# Downloads públicos

Instaladores do BRS Downloader servidos pelo site para atualização no app.

Mantenha apenas a versão atual do instalador nesta pasta: cada `.exe` é incluído em todo deploy e ocupa espaço de armazenamento. Versões antigas devem ir para GitHub Releases ou outro CDN.

- `BRS-Downloader_1.0.36_x64-setup.exe` — Windows x64 (NSIS) — versão atual
- `BRS-Android_1.0.0-debug.apk` — Android (debug), app WebView do site

Allavsoft: download externo via Workupload, configurável por `ALLAVSOFT_DOWNLOAD_URL`.
